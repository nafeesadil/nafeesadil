## 🛠️ Featured Projects

### Hygia — Persuasive Hygiene Tracking App

**Flutter | Dart | Firebase | Firestore | Drift | SQLite**

A mobile app prototype developed for my Master's thesis. Hygia supports hygiene behaviour improvement among street food vendors through daily hygiene tasks, XP, vendor scores, task levels, streaks, customer QR rating, and offline-first local storage.

Repository: [hygiene_v_1](https://github.com/nafeesadil/hygiene_v_1)

Key features:

* Offline-first task tracking
* Vendor score and XP system
* Daily hygiene checklist
* Task levels and streaks
* Firebase Authentication and Firestore integration
* QR-code based customer feedback concept
